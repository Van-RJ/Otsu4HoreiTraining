# 乙4 法令トレーニング

危険物取扱者 乙種第4類の「危険物に関する法令」59問を学習する、静的Webサイトです。問題データは `data/problems.js` だけを情報源として使用します。

## 起動方法

依存パッケージやビルドは不要です。`index.html` をブラウザで開くか、任意の静的Webサーバーでこのディレクトリを配信してください。

例:

```powershell
python -m http.server 8000
```

その後、`http://localhost:8000/` を開きます。すべて相対パスなので、GitHub Pagesのリポジトリ配下でも動作します。ES Modulesの `file://` 読み込みを制限するブラウザでは、上記のローカルサーバーを使用してください。

## GitHub Pages

1. このフォルダの内容をGitHubリポジトリへpushします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Deploy from a branch** を選び、公開ブランチと `/ (root)` を指定します。

外部CDN、外部フォント、DB、サーバー処理は使用していません。

## 主な機能

- 全問題、ランダム10問・20問、未回答、間違えた問題、お気に入り、あとで解く、分野別
- 回答確定前の選択、解説・覚え方・要確認メモ、再回答、中断・再開
- 結果集計、間違いだけ／同じセットの再挑戦
- 全体統計、分野別進捗、最近の間違い、間違い回数、低正答率
- `localStorage` への自動保存（バージョン1）、JSONエクスポート／インポート／全削除
- ライト／ダーク／端末設定、キーボード操作、ARIA、セーフエリア対応
- 起動時の問題データ検証。不正問題は出題対象から除外し、コンソールに理由を表示

## キーボード操作

- 問題画面で `1`〜`5`: 選択肢を選ぶ
- `Enter`: 回答を確定／次の問題へ
- `Escape`: 中断してホームへ戻る

## 保存データ

履歴はブラウザの `localStorage` にのみ保存されます。ブラウザデータを削除すると履歴も消えるため、必要に応じて設定画面からJSONを書き出してください。インポート時は型検査を行い、未知の問題IDや不正値を除外します。
